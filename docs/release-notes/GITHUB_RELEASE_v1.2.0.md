## NextTry StatusTracker 1.2.0

### Highlights

- Per-player notes, notifications, roles and editable tags
- Aligned role icons for raid lead, tank, healer and damage dealer
- 32-pixel class and alliance icons after character names in the tooltip
- Clear per-player tag add/remove controls and global tag management
- Compact last-seen time with last known character and zone for offline players
- Automatic correction of a missing `@` during manual player entry
- Extended hover tooltip and player-management settings
- Separate blink backdrop that preserves the normal row background

### Compatibility

- ESO APIs 101050 and 101051
- LibAddonMenu-2.0 r43 or newer
